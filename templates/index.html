Project summary

This dashboard is a single-file static HTML template for presenting classification results for the Introvert vs Extrovert problem. It includes space for model comparisons, metrics, ROC/PR charts, confusion matrices and a simple front-end predict form (requires a backend endpoint to function).

  • Drop-in JSON for metrics, confusion matrices and ROC data.
  • Interactive charts (Chart.js).
  • Predict form that posts JSON to /predict (change to your API).
Instructions
  1. Replace placeholder JSON in the Metrics panel or call loadReport(url).
  2. Provide model artefacts/plots as static images or URLs.
  3. Wire the predict form to your inference endpoint (POST /predict).
